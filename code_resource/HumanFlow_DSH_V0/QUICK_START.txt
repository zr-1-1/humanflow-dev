HumanFlow DSH V0 — 最短试用流程

1. 把 .agents 和 .ai-collab 复制到你的 Git 仓库根目录。
2. 填写 .ai-collab/conventions.yaml 和 state.yaml。
3. 启动 DeepSeek Harness，打开该仓库。
4. 输入：
   /permission read-only
5. 调用：
   /hf-project-audit
6. 选一个 Finding 后：
   /hf-inspect
7. 确认问题后：
   /hf-propose
8. 人确认方案。
9. 修改 scope.yaml，然后：
   /permission workspace-write
   /hf-micro-patch
10. 查看 DSH 的逐文件 Diff。
11. 调用：
   /hf-review-diff
12. 完成后切回：
   /permission read-only

第一版不要启用 Fix All / Auto loop / 大规模自主重构。
